# Project conventions

- Работы с новой EA/UML-структурой шкафов в Редакторе электрических схем выполнять изолированно: не изменять старую структуру/каталог и не добавлять на них импорты или ссылки. Новая функциональность размещается в отдельной вкладке и отдельном модуле.
- Вкладка `UML тест` — изолированная площадка: `ea_uml_test.py` читает `EA/cabinets_uml.json`, использует собственные `Toplevel`, `Canvas` и state-JSON; из `main.py` получает только Tk root через lazy-методы.
- `Cabinet.standard` в `EA/structure.xml` и `EA/cabinets_uml.json` равен имени исходного DOCX без расширения: `Раздел 4.16_т. 5_СТО ШЭТ СКРМ II_Ред.2`.
- Архитектура редактора: `main.py` — неизменный графический движок; `editor_engine.py` — адаптер; `editor_app.py` — новая точка входа; `structure_core` — реестр/контракт плагинов/менеджер; `structures` — плагины UML-схем через `manifest.json`. Новые UML-схемы подключать записью в манифест и модулем с `create_plugin(config, root)`.
- Слой `structure_core`/`structures` не должен импортировать модули старой структуры или графического движка; композиция выполняется только в `editor_app.py`.
