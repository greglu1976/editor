# 2026-11-04

## structure.json переведён на формат v3 (КЭТ → шкафы → комплекты → ИЭУ)

Правила модели (по запросу пользователя): шкаф состоит минимум из одного
комплекта; комплект бывает с ИЭУ или без (обязательный булевый признак
«есть ИЭУ», «иэу» только при true); единственное ИЭУ в описании шкафа
переносится в комплект, а сводные GOOSE / испытательные блоки — в это
ИЭУ / этот комплект.

Изменённые файлы:
- `komplekts.py` — `ensure_cabinet_kits()` (идемпотентная миграция
  `cabinet["ieds"]`, удаление поля), `cabinet_single_ied()`,
  `kit_composition()`, `cabinet_ieds()`;
- `cabs.py` — `normalize_cabinet()` вызывает миграцию;
- `tools/build_structure.py` — версия 3, вложенные комплекты/ИЭУ, перенос
  сводных таблиц при одном владельце;
- `structure.py` — API `ieds_of/has_ied/cabinets/containers/kits/ieds`,
  `cabinet_of_kit`, подписи узлов, `format_kit_full`, сводка;
  `SUPPORTED_VERSIONS = (2, 3)` (v2 читается, признак ИЭУ выводится);
- `main.py` — вместо текстовых окон один проводник `_structure_browser`
  (Treeview + Text, фильтр «Все / С ИЭУ / Без ИЭУ», F5/Esc), фильтры и
  счётчики в каталогах шкафов/комплектов и в диалоге `_choose_komplekt`;
  исправлен `show_selected_structure`: `selected_elements` хранит id,
  объекты берутся из `self.elements`;
- `tools/check_structure.py`, `tests/test_structure_docking.py`,
  `STRUCTURE.md` — переписаны под v3.

Проверено: сборка даёт 17 КЭТ / 308 шкафов / 339 комплектов
(322 с ИЭУ, 17 без) / 322 ИЭУ; checker и тесты (данные + GUI на
`/c/Python310/python.exe`, у WorkBuddy-Python нет tkinter) проходят;
негативный тест проверщика ловит 7 нарушений; v2-совместимость работает.

Запуск: `python tools/build_structure.py --stats`,
`python tools/check_structure.py`,
`python tests/test_structure_docking.py --no-gui`,
`/c/Python310/python.exe tests/test_structure_docking.py`.

Известно: `standards/src` пуст (`recover_kb_docs.py` ничего не восстанавливает
в этом окружении), поэтому «толстые» таблицы СТО по ИЭУ отсутствуют;
`structure.json` — генерируемый артефакт в `.gitignore`.

## Уточнение кнопки «Обновить из файла» (вопрос пользователя)

Кнопка в `_structure_browser` только сбрасывает кэш `structure.py` и читает
заново `G:\editor\structure.json`; не запускает сборку и не читает каталоги,
PDF, БЗ. Чтобы правки каталогов попали в окно: сначала
`python tools/build_structure.py`, потом F5.

Переименована в «Перечитать structure.json (F5)»; в шапку окна добавлен путь
к файлу-источнику, корневой узел дерева показывает версию и mtime файла;
`reload_structure()` теперь показывает ошибку, если файл недоступен.
Обновлены `STRUCTURE.md` (раздел «Что делает Перечитать structure.json») и
GUI-тесты (проверка подписей и `invoke()` кнопки). Все тесты проходят.
